# page-retry

Find changed, missing or repeated rows in a paginated table export. [Examples and quick start](skills/page-retry/tool/README.md)

Install the skill and give it a JSON plan with rows you transcribed from the original document and a paginated text export of the same document. It returns the physical pages and reference indices that need review. The offline runtime requires Node.js 18 or later.

```text
/plugin install page-retry --marketplace thinx-pro/agent-preflight
```
